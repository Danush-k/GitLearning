# 🌿 GitLearning — Learn GitHub Basics

A beautifully designed, interactive website to help beginners learn Git & GitHub fundamentals.

## 📚 What's Inside

- **Git Basics** — Core concepts explained simply
- **Common Commands** — Interactive command reference cards
- **Git Cheatsheet** — Quick-reference guide
- **Mini Quiz** — Test your knowledge

## 🚀 Getting Started

Just open `index.html` in your browser — no build tools needed!

## 🛠 Tech Stack

- HTML5
- CSS3 (custom design system, no frameworks)
- Vanilla JavaScript

## 📖 Topics Covered

1. What is Git?
2. Repository basics
3. Staging & Committing
4. Branching & Merging
5. Push, Pull & Remote
6. GitHub workflow
